3. PROJECT LIST
==================================================

GET /api/projects

Return projects appropriately for the authenticated user or the existing application design.

  "success": true,
  "data": ...,
  "message": "..."
}

Never return sensitive user information.

Include project owner information only when safe and necessary.

==================================================
4. CREATE PROJECT
==================================================

POST /api/projects

Require authentication.

Accept:

{
  "title": "...",
  "description": "...",
  "techStack": ["React", "Node.js", "PostgreSQL"],
  "githubUrl": "...",
  "liveUrl": "...",
  "imageUrl": "..."
}

Use the authenticated user as the project owner.

DO NOT allow the frontend to provide an arbitrary owner/user ID.

Validate:

- title required
- reasonable title length
- description reasonable length
- techStack valid
- URLs valid when provided

Return the created project using the standard API response.

==================================================
5. GET SINGLE PROJECT
==================================================

GET /api/projects/:id

Return the project details.

Handle:

- project not found
- invalid ID
- unauthorized access where applicable

Use consistent errors:

{
  "success": false,
  "data": null,
  "message": "Project not found"
}

==================================================
6. UPDATE PROJECT
==================================================

PUT /api/projects/:id

Require authentication.

Only the project owner can update their project.

Do NOT allow users to modify another user's project.

Allow updating:

- title
- description
- tech stack
- image URL
- GitHub URL
- live URL

Use partial update behavior where appropriate.

==================================================
7. DELETE PROJECT
==================================================

DELETE /api/projects/:id

Require authentication.

Only the owner can delete the project.

Return:

{
  "success": true,
  "data": null,
  "message": "Project deleted successfully"
}

Handle unauthorized access safely.
