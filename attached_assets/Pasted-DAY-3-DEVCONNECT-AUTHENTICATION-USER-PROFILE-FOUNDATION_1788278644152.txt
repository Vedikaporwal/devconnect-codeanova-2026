--------------------------------------------------
1. AUTHENTICATION
--------------------------------------------------

Implement secure authentication using:

- Email
- Password
- JWT
- bcrypt/bcryptjs password hashing

Create:

POST /api/auth/register

POST /api/auth/login

POST /api/auth/logout

GET /api/auth/me

Expected API response format:

{
  "success": boolean,
  "data": any,
  "message": string
}

Registration:

Request:
{
  "name": "Developer Name",
  "email": "developer@example.com",
  "password": "password123"
}

Requirements:
- Validate name
- Validate email
- Validate password
- Prevent duplicate email registration
- Hash passwords before storing
- Never return password hashes to the frontend
- Generate JWT after successful registration
- Return safe user information

Login:

Request:
{
  "email": "developer@example.com",
  "password": "password123"
}

Requirements:
- Validate credentials
- Compare hashed password
- Return JWT and safe user information
- Never expose password/hash

Authentication middleware:

Create reusable authentication middleware that:
- Reads the JWT securely
- Verifies the JWT
- Identifies the current user
- Attaches the authenticated user to the request
- Returns a consistent 401 response for invalid/missing authentication
