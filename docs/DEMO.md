# DevConnect Demo Flow

Use two test accounts to demonstrate social actions and notifications.

1. Open the landing page.
2. Register or log in.
3. Complete the profile and add skills.
4. Create a project with links and an image.
5. Write and publish a blog.
6. Open Discover and filter developers.
7. Open another public profile and send a connection request.
8. Log in as the second account and accept the request.
9. Endorse one of the developer's profile skills.
10. Show the real-time notification bell updating without a refresh.
11. Open the dashboard and show real project, blog, connection, endorsement, activity, suggestion, and published-blog data.
12. Test the same flows at mobile width.
13. Log out, log in again, and verify the HTTP-only session persists correctly.

Do not use fake production data. Any test records should be created with clearly labeled test accounts.
